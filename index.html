Raw data → MIDI

datamusak listens to live open data — the Danish power grid, DMI weather stations, lightning, tide gauges, air-quality sensors, bike share, aircraft, ships on open MQTT brokers, Nostr relays, a WebTorrent swarm, Wikipedia edits, Bluesky posts and more — and turns every data point into a note.

Install it as an app from your browser menu: the shell works offline, and instruments are cached once they have been played. Your settings and presets are saved in this browser.

Online joins a peer-to-peer room (Trystero over public Nostr relays) to count other listeners and pass played notes between you — like any WebRTC app, peers can see each other's IP address. Switch it off any time with the button in the header.

Want another data source? Suggest one or read how to add one.

Each source has a mapping: choose which data field drives pitch, velocity, note length, stereo pan and brightness (sent as MIDI CC74), the value range for each, and which instruments it plays. Pitch is always snapped to the chosen scale. Fields without a fixed physical range learn their range automatically from recent data.

Slow data (prices, weather, grid) is played as a looping step sequence over the latest values, so it changes gradually as new data arrives. Fast streams (ships, edits, posts, trades) trigger notes directly and are limited by max notes/s.

Everything runs in your browser: data is fetched directly from each provider's public, CORS-enabled API or WebSocket. If a provider is down or blocks browsers, its status dot turns red — the rest keep playing.

Enable MIDI out to drive a DAW or hardware synth (Chrome/Edge): instrument slot n sends on channel n, drums on channel 10.
